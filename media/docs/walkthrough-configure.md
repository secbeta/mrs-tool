**[打开配置页面](command:mrsToolbox.configure)**（也可从侧边栏 MRS Toolbox 视图的齿轮按钮、状态栏齿轮进入），像 ESP-IDF 扩展的配置页一样：

### MounRiver Studio 2 安装

- 显示当前使用的安装与解析结果（工具链、芯片库、make、openocd）
- 列出本机探测到的所有安装，一键"使用"，或"浏览…"手动选择
- "改回自动探测"恢复默认行为

### 例程库（可添加多个）

每个库是一个包含 `<芯片>/EVT/EXAM/<分类>/<例程>` 结构的目录。

- **+ 添加例程库…** —— 浏览选择目录，自动扫描并显示识别到的例程数与芯片列表
- 每个库可单独**打开**（资源管理器）或**移除**（只从扩展移除，不删除文件）
- Examples 视图按库分组浏览；导入工程时共享源码池也会在所有库中查找

### 常用设置

调试提供方（cortex-debug / cppdbg / 自动）、烧录后校验、擦除模式、OpenOCD 端口 —— 都在页面上直接改，写入对应设置项。

[打开配置页面](command:mrsToolbox.configure)
